# Suggested Commands
- `npm run dev` starts Vite on all interfaces, port 3000.
- `npm run build` runs `tsc` then `vite build`.
- `npm run preview` serves the production build on all interfaces, port 3000.
- `npm run build:podman` builds in a Node Alpine Podman container when host tooling is unsuitable.
- No dedicated test, lint, or format script is configured.
