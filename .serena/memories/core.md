# Core
- Static TypeScript/Vite personal portfolio site.
- UI composition: `index.html` defines semantic sections; `src/main.ts` wires DOM interactions and feature modules; CSS is split into `src/styles/main.css` and `src/styles/components.css`.
- Page domains: hero, philosophy, topology, projects, footer.
- Read `mem:tech_stack` for build/runtime constraints; `mem:conventions` for module boundaries; `mem:suggested_commands` and `mem:task_completion` for validation.
